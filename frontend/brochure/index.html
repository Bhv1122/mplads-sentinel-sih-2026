Technical Foundation

Four-Tier Scalable System Architecture

Engineered for 100% relational integrity, sub-second query performance, and resilient offline demonstration fallback.

1. Presentation Tier

Responsive Vanilla CSS & Tailwind tokens, Material Symbols, mobile-ready field layouts, and interactive action modals.

2. API Gateway

FastAPI (Python 3.12), Pydantic v2 schemas, OpenAPI Swagger UI, and automated in-memory session fallback.

3. Predictive ML

Dual-context feature contracts (Pre-award inherent risk vs. In-flight surveillance) with deterministic XAI causal factor trees.

4. Relational DB

PostgreSQL 16+ with 13 tables (3NF), 8 precomputed analytical views, and 85 GIN, B-Tree, and TSVECTOR indexes.
